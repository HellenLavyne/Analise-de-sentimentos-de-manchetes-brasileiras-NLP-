# Análise de sentimentos de manchetes brasileiras utilizando NLP

Neste projeto foram realizadas aplicações de técnicas de Processamento de Linguagem Natural (NLP) para analisar manchetes jornalísticas brasileiras e investigar sua relação com sentimentos. 
O dataset utilizado para esta análise foi o _brazilian headlines sentiments_. Ele é composto por manchetes jornalísticas e informações relacionadas ao sentimento associado a cada texto. 

O projeto envolve diferentes etapas desde o pré-processamento dos dados e leitura, incluindo limpeza dos dados, normalização, tokenização, lematização, análise exploratória até avaliação quantitativa dos resultados. Também são comparadas diferentes formas de representação texual, especificamente _Bag of Words_ e _TF-IDF_, juntamente com diferentes algoritmos de aprendizado de máquina.
